# Homebrew tap for mcc

Formulae for [MCC — Mac Cache Cleaner](https://github.com/crisacm/mac-cache-cleaner).

## Install

```bash
brew tap crisacm/tap
brew install mcc
```

Or in one line:

```bash
brew install crisacm/tap/mcc
```

The formula builds the binary from source, so Homebrew installs Go as a build
dependency. Check the installed version with `mcc --version`.
